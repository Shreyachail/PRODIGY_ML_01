# House Price Prediction using Linear Regression

## Task-01 - Prodigy InfoTech Machine Learning Internship

### Objective

The objective of this project is to implement a Linear Regression model to predict house prices based on:

- Living area (GrLivArea)
- Number of bedrooms (BedroomAbvGr)
- Number of full bathrooms (FullBath)
- Number of half bathrooms (HalfBath)

### Dataset

The dataset used is the Kaggle House Prices dataset.

Dataset:
https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data

### Algorithm Used

Linear Regression

### Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

### Model Evaluation

The model was evaluated using:

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score

Results:

- MAE: 36018.56
- RMSE: 53018.33
- R² Score: 0.6335

### Prediction Example

For a house with:

- Living Area: 2000 sq ft
- Bedrooms: 3
- Full Bathrooms: 2
- Half Bathrooms: 1

The predicted house price was approximately:

**$242,491.45**

### Project Outcome

A Linear Regression model was successfully implemented to predict house prices using selected house features.
